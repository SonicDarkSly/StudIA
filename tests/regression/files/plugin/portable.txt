=== revue-code/README.md (modele)
# Plugin `revue-code`

Ce plugin ajoute une skill pour relire les modifications en cours dans un dépôt Git avant d’effectuer un commit.

## Fonctionnalités
- Analyse les fichiers ajoutés via `git add` (via `git diff --cached`)
- Résume les changements par fichier
- Propose une synthèse globale
- Demande confirmation avant le commit
- Suggère des corrections si nécessaire

## Installation
### Pour Copilot CLI :
```bash
copilot plugin install ./revue-code
```

### Pour Cursor :
Copiez le dossier `revue-code` dans :
```
~/.cursor/plugins/local/revue-code/
```

### Pour Codex / Gemini CLI / Antigravity :
Ce plugin est compatible avec les formats standards. Installez-le via le marketplace ou en copiant manuellement dans le répertoire des plugins du client.

## Utilisation
1. Après avoir exécuté `git add`, lancez la skill `relire-modifications`.
2. L’IA vous affiche un résumé des changements.
3. Confirmez ou demandez des corrections.
4. Validez le commit si tout est correct.

## À vérifier
- Le plugin ne nécessite aucun serveur MCP : il utilise uniquement `git` disponible localement.
- Assurez-vous que `git` est installé et que vous êtes dans un dépôt Git valide.
- Si l’outil cible ne supporte pas les skills directement, vérifiez la documentation du plugin pour l’intégration.
- Le nom `revue-code` respecte les règles de nommage (minuscules, tirets).
