=== revue-code/README.md (modele)
# Plugin `revue-code`

Ce plugin permet de vérifier les modifications en cours dans un dépôt Git avant d'effectuer un commit. Il analyse les fichiers ajoutés (`git diff --cached`) et non ajoutés (`git diff`), puis fournit un résumé clair des changements, avec détection des grandes modifications.

## Fonctionnalités
- Analyse des différences entre le working directory et l'index (staged).
- Résumé structuré : fichiers modifiés, type de modification, nombre de lignes.
- Suggestion de message de commit basée sur les changements.
- Recommandation finale pour vérification.

## Installation
1. Placez le dossier `revue-code` dans un répertoire accessible (ex: `~/plugins/revue-code`).
2. Lancez Claude avec le plugin activé :
   ```bash
   claude --plugin-dir ./revue-code
   ```
3. Validez l'installation :
   ```bash
   claude plugin validate ./revue-code
   ```

## Utilisation
Dans Claude Desktop, utilisez la commande suivante pour déclencher la revue :
```
/revue-code:revue-modifications
```

Le plugin affichera un résumé des modifications et suggérera un message de commit.

## À vérifier
- Le dépôt Git doit être initialisé (`git init`) et avoir des fichiers modifiés.
- L'utilisateur doit avoir `git` installé et accessible dans le PATH.
- La commande `git diff` doit fonctionner correctement dans le contexte d'exécution.
- Si l'utilisateur utilise un environnement non standard (ex: WSL, Docker), vérifiez que les chemins Git sont accessibles.
